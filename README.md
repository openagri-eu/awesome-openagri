# Awesome OpenAgri [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of open-source tools, platforms, datasets, and hardware outcomes developed within the [OpenAgri](https://github.com/openagri-eu) project.

*Inspired by [Bryce Johnston](https://github.com/brycejohnston)'s [`awesome-agriculture`](https://github.com/brycejohnston/awesome-agriculture) project. A special thanks to Bryce for cultivating open-source curation in agtech!*

The OpenAgri initiative focuses on empowering sustainable, data-driven, and open agriculture. This repository serves as a central index for all open-source deliverables, software components, and research outcomes produced across the consortium.

## Platforms & Software

- [OpenAgri Prescription Map Editor (EDEN)](https://github.com/Eden-Library-AI/openagri_prescription_map_editor) - Prescription-map editing tool.

- Colorado Potato Beetle Detection Engine - Detection engine for Colorado potato beetles.
- Visualisation Framework for Colorado Beetle detections - Visualisation framework for beetle detections.
- [OpenAgri Smart Irrigation Controller](https://gitlab.pcss.pl/openagri/openagri-smartirrigationcontroller) - Smart irrigation controller.

- [Compost Reasoning Engine](https://github.com/fedjo/monicompost) - Compost reasoning engine.
- [AgriVision](https://github.com/GEvang/agrivision-pipeline) - AgriVision software.
- AgriTwin - AgriTwin software.
- [Spotify](https://github.com/BSPOKEGR/spotifly) - Spotify software.

- [Pre-Configured Reporting Templates for PGI/DPO](https://github.com/Agrobitsrl/reporting-templates) - Reporting templates for PGI/DPO.
- [SheepCare](https://github.com/itdepartment-cnta/Sheepcare.git) - SheepCare software.

- [SFS SmartFeed Web App](https://github.com/inokron-doo/OA-Cloud-Frontend) - SmartFeed web application.

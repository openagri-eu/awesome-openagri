# Contributing Guidelines

Know an open-source agricultural tool, platform, dataset, hardware project, or resource that belongs in this list? Open a pull request or file an issue. Contributions are welcome.

## Guidelines

- Add one entry per pull request.
- Use the format: `- [project-name](https://example.com/) - Short, factual description.`
- Keep descriptions concise and explain what the resource does.
- Add a new category only when none of the existing categories fit. Add it to the README contents list.
- Check the README and open issues before proposing an entry to avoid duplicates.
- Link to the resource's primary repository, project page, documentation, dataset record, or other canonical source.
- Check spelling, grammar, Markdown rendering, and links before submitting.
- Do not add trailing whitespace.
